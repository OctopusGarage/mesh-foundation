# Getting help

Read the [quick start](README.md#quick-start), [crate composition](docs/sdk-composition.md)
and [delivery guide](docs/sdk-delivery.md) first. API documentation can be generated
with `cargo doc --locked --workspace --all-features --no-deps --open`.

Use GitHub issues for reproducible bugs, integration questions and feature
proposals. Search existing issues first; include the SDK commit, crate/features,
Rust version, operating system and a minimal sanitized example. Support is
best-effort. For confidential security reports, use [SECURITY.md](SECURITY.md).
